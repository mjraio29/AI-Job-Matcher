# 🤖 AI Job Matcher

An AI-powered job search assistant that parses your resume, finds matching jobs, scores your fit, and generates personalized cover letters.

🔗 **Live App:** https://ai-job-matcher-791w.onrender.com

## ✨ Features
- 📄 **Resume Parser** — Upload PDF or DOCX and extract key information
- 🔍 **Job Listing Importer** — Search live job listings by keyword via RemoteOK
- 🎯 **AI Match Scorer** — AI-generated match score with skill gap analysis
- ✉️ **Cover Letter Generator** — Tailored cover letter for any job in seconds
- 🌐 **Web Interface** — Clean browser-based UI

## 🛠️ Tech Stack
- **Backend:** Python 3.12, FastAPI, Uvicorn
- **AI:** Cohere AI
- **Resume Parsing:** pdfplumber, python-docx
- **Job Data:** RemoteOK API
- **Deployment:** Render
